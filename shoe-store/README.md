# Shoe Store

Local shoe store MVP scaffold with a React + Vite client and Node.js/Express API.

## Requirements

- Node.js 20 or newer
- npm
- PostgreSQL client tools for later database setup tasks

## Setup

```bash
npm install
cp server/.env.example server/.env
```

## Scripts

```bash
npm run dev
npm run test
npm run build
```

- Frontend: `http://0.0.0.0:5173`
- Backend: `http://0.0.0.0:5000`
- Health check: `GET /api/health`
